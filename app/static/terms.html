이용약관

시행일 2026-08-17 · 최종 개정 2026-08-17

Mulmit(mulmit.com)은 무료로 공개된 시장 데이터 대시보드입니다. 이 약관은 사이트와 공개 API를 이용할 때 적용됩니다.

1. 서비스의 성격

Mulmit은 공개된 시장·거시·공시 데이터를 모아 보여주는 정보 서비스이며, 개인이 운영하는 비상업적 프로젝트입니다. 회원가입이나 요금이 없고, 이용자와 별도의 계약을 맺지 않습니다.

Mulmit은 금융투자업자가 아니고 투자 자문을 제공하지 않습니다. 자세한 내용은 면책 고지를 반드시 함께 읽어 주세요.

2. 이용 조건

사이트를 여는 것만으로 이 약관에 동의한 것으로 봅니다. 다음 행위는 허용되지 않습니다.

  • 서비스 운영을 방해할 정도의 과도한 자동 요청
  • 요청 빈도 제한을 우회하기 위한 헤더 위조나 분산 요청
  • 서버·인프라에 대한 무단 침입 시도, 취약점 스캔, 서비스 거부 공격
  • Mulmit이 제공하는 정보를 투자 자문인 것처럼 재배포하거나, 출처를 왜곡해 인용하는 행위

보안 취약점을 발견하면 공개적으로 게시하기 전에 GitHub 이슈로 알려 주세요.

3. 공개 API 사용

/api/ 경로는 인증 없이 열려 있습니다. 다만 열려 있다는 사실이 무제한 사용이나 재배포 권리를 뜻하지는 않습니다.

  • 요청 빈도 제한이 적용되며, 초과 시 429가 반환됩니다.
  • 응답 구조와 필드는 사전 공지 없이 바뀔 수 있습니다. 운영 목적의 의존은 권장하지 않습니다.
  • 가장 중요한 점: 응답에 담긴 값에는 각 원 제공자의 이용 조건이 그대로 적용됩니다. Mulmit을 경유했다고 해서 그 조건이 사라지지 않습니다. 받은 값을 재배포하거나 상업적으로 이용하려면 원 제공자에게 직접 권리를 확인해야 합니다.
  • 각 응답의 source와 rights 필드에 출처와 조건이 함께 담겨 있습니다.

4. 데이터 출처와 표시 상태

Mulmit은 표시 권리가 확인된 데이터만 공개합니다. 확인 전이거나 계약이 필요한 지표는 값을 만들어 채우지 않고 상태만 표시합니다. 공급자별 판정 근거는 저장소의 데이터 공급자·권리 등록부에 공개되어 있고, 현재 각 데이터 경로의 상태는 /api/status에서 볼 수 있습니다.

원 제공자의 조건이 바뀌거나 권리가 확인되지 않으면 해당 데이터는 예고 없이 비활성화될 수 있습니다.

5. 지식재산권

Mulmit의 소스코드는 저장소에 공개되어 있으며 해당 라이선스를 따릅니다. 반면 사이트에 표시되는 시장 데이터 자체의 권리는 각 원 제공자에게 있으며 Mulmit에 있지 않습니다. Mulmit이라는 이름과 화면 디자인은 운영자에게 귀속됩니다.

6. 서비스 변경과 중단

비상업적 개인 프로젝트이므로 특정 수준의 가용성을 약속하지 않습니다. 기능, 데이터 항목, API 경로는 사전 공지 없이 추가·변경·중단될 수 있으며, 서비스 전체가 종료될 수도 있습니다.

7. 면책

Mulmit은 있는 그대로(as-is) 제공되며, 정확성·완전성·적시성·특정 목적 적합성을 보증하지 않습니다. 관련 법령이 허용하는 범위에서, Mulmit의 이용 또는 이용 불가로 발생한 직접· 간접·부수적 손해에 대해 책임지지 않습니다. 투자 판단과 그 결과는 이용자 본인의 책임입니다. 전체 내용은 면책 고지를 참고하세요.

8. 개인정보

Mulmit은 계정을 만들지 않고 쿠키를 사용하지 않습니다. 처리하는 정보의 범위는 개인정보처리방침에 적혀 있습니다.

9. 약관 변경

약관이 바뀌면 이 페이지의 시행일을 갱신합니다. 변경 이후에도 사이트를 계속 이용하면 변경된 약관에 동의한 것으로 봅니다.

10. 준거법

이 약관은 대한민국 법에 따릅니다.
