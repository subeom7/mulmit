## 2. 채점 규칙 (프로브가 정한 것)

1. **기준가(스냅샷)** = 공시일(rcept_dt) 종가, 동결. FSC 공개가 T+1
   13:00이라 카드 생성 직후엔 **"기준가 대기" 상태가 정상**이다 — 라이브
   보드의 상태 기계에 포함시킨다(없는 값을 발명하지 않는다).
2. **수익률** = D0 다음 행부터 (1+fltRt/100) 연쇄곱. 원시 clpr 비율과의
   괴리가 문턱을 넘으면 기업행동 구간으로 주석.
3. **체크포인트** = +21/+63/+126 영업일 (1/3/6개월).
4. **벤치마크** = 같은 달력 구간의 코스피(코스닥 상장은 코스닥) 연쇄곱,
   초과수익은 %p로 표기.
5. **정지** = trqu 0. 정지일 수를 카드에 표기, 전 구간 정지면 채점 보류.
6. **소급 하한** = 2020-01-02. 그 이전 공시는 기록만.
7. **표현** = DIRECTION §4 표현 규칙 그대로 — 집계·이벤트 단위, 보고자
   단위 랭킹 보류, 추천 표현 금지(테스트가 문구를 지킨다).

## 3. 남은 설계 결정 (구현 시)

- 저장 스키마: 이벤트(공시) 테이블 + 일일 채점 잡. 배치 payload `SCHEMA`
  버전 규칙 준수(ROADMAP 2026-08-25 사고 기록).
- 신규 판별 정확도: `signal_feed`의 기존 대량보유 처리를 읽고 재사용 —
  프로브는 필드만 확인했고 규칙 통일은 구현에서.
- majorstock 걷기: 라이브 보드 배포와 동시 시작(§1 롤링 창).
- 페이지: 스코어보드 SSR(가칭 `/score`) — `/weekend` 문법(상류 호출 없는
  요청 경로, 사이트맵·내부 링크), 카드→종목 페이지 상호 링크.
- 백필: majorstock이 닿는 2024-09~ 먼저. 그 이전(원문 파싱)은 별도 판정
  전 보류.
