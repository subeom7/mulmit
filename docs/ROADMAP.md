# Mulmit 로드맵 — 위시리스트 판정표

작성일: 2026-08-18. 운영자 위시리스트 전체를 등록부 원칙(도달 가능 ≠ 재배포 가능,
fail-closed, 수치 발명 금지)으로 판정한 문서다. 실행 순서의 단일 진실.
관련: `docs/DATA_SOURCE_REGISTER.md`, `docs/PLAN_KR_SECTIONS.md`(hlkr 매핑),
`docs/PLAN_SITE_SPLIT.md`(리디자인).

## 확정 실행 순서 (2026-08-18 합의)

1. **ETF 시세** — 운영자 활용신청(아래 §1) 후 기존 FSC 패턴 재사용. 공수 小.
2. **페이지 분리 + 리디자인** — `/`(랜딩) · `/kr` · `/us`. "가장 급함"으로 지정.
   설계는 `docs/PLAN_SITE_SPLIT.md`.
3. **US PTR (미국 정치인 거래)** — 상·하원 STOCK Act 공시 파서. 미국 페이지의
   킬러 콘텐츠.

## §1 ETF 활용신청 (운영자 액션, 1회)

1. https://www.data.go.kr/data/15094806/openapi.do 접속 (금융위원회_증권상품시세정보)
2. 로그인 → **활용신청** → 활용목적은 기존 주식시세정보 신청 때와 동일하게
   (mulmit.com 시장 대시보드, 출처 표기) → 자동승인
3. 키는 기존 data.go.kr 키와 동일하게 발급되므로 서버 변경 불필요할 가능성 큼
   (같은 키로 호출만 열림 — 승인 후 확인)

## §2 React 전환 판정 — **지금은 하지 않는다**

- **SEO가 유입 전략의 핵심**("주말 삼성전자 얼마" 검색 수요)인데, 현 구조(서버가
  주는 정적 HTML + JS 데이터 주입)가 클라이언트 렌더 SPA보다 검색 노출에 유리하다.
- 페이지 분리·새 디자인은 현 스택으로 전부 가능하다 — 병목은 프레임워크가 아니라
  정보 구조다.
- 전환 비용(빌드체인, 371개 테스트와 별개인 프론트 테스트 체계, 재작성 리스크)이
  현 화면 복잡도 대비 크다.
- **재검토 조건**: 실시간 피드·예측 이벤트처럼 상태가 많은 인터랙티브 기능이
  실제로 들어오는 시점.
