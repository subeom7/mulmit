# Mulmit 제품 방향 — 기록이 제품이다

작성일: 2026-08-26. 운영자 질문("사이트에 변별력이 없다. 커뮤니티로 갈까,
언어는 하나만 골라야 하나, 모바일은 언제")에 대한 PM 판정과 단계 계획.
**제품 방향의 단일 진실**이다. 역할 분담 — 실행 순서·판정 이력은
`ROADMAP.md`, 커뮤니티 규제 상세는 `PLAN_COMMUNITY.md`, 권리는
`DATA_SOURCE_REGISTER.md`. 이 문서는 "왜, 무엇을, 어떤 순서의 논리로"만
말한다.

## 0. 요약

- **진단**: 기능은 복제 가능하고, 병목은 기능이 아니라 유입이다
  (2026-08-24 실측: 색인 5 / 미색인 2,957, 5일간 검색 클릭 2회).
- **테제**: 변별력은 기능이 아니라 **소급 생성이 불가능한 축적**에서
  나온다. "말한 것은 기록되고, 기록된 것은 채점된다."
- **결정 다섯**: ① 한국어 단일(커뮤니티 층 기준) ② 채점 엔진을 유저 없이
  **공시 데이터에 먼저** 돌려 콘텐츠로 발행 ③ 유입이 증명되면 계정+콜
  보드(게시판 아님) ④ 자유 게시판은 마지막 ⑤ TWA 파이프라인은 지금
  병행(코드가 아니라 행정 대기가 길어서).

## 1. 진단 — 2026-08 실측

**유입이 병목이다.** 색인 5 / 미색인 2,957(08-24), 총 검색 클릭 2회
(08-18~22), 월 수백 PV. "이 사이트의 문제는 기능이 아니라 유입"이라는
판정은 `/weekend`(08-25) 때 이미 내렸고, 이 문서는 그 판정을 제품
전략까지 확장한다.

**기능은 복제 가능하다.** 모든 원천이 공개 API라 사이트 자체는 AI로 수
주면 재현된다. 외부 조언이 짚은 세 결핍 — 데이터 소유권 · 스위칭 코스트 ·
배포 채널 — 은 정확하다.

**그러나 복제 불가능한 자산의 싹이 이미 셋 있다:**

| 자산 | 왜 복제 불가인가 |
|---|---|
| 자가 축적 시계열 (스테이블코인 공급·도미넌스 일별 등) | 원천이 현재값만 주는 데이터는 오늘 시작하지 않으면 영원히 없다. 소급 백필 불가 |
| 등록부 (`DATA_SOURCE_REGISTER.md`) | 무엇을 합법적으로 표시할 수 있는지의 지도. 빨리 베낀 경쟁자는 수익화 시점에 권리에서 먼저 넘어진다 |
| 운영 규율 (스냅샷 동결·fail-closed·수치 발명 금지) | 채점 제품이 요구하는 성질과 정확히 같다 — 이 규율 없이 만든 랭킹은 신뢰를 못 얻는다 |

전략은 이 셋을 늘리는 것이고, 신설할 네 번째가 **아웃컴 기록**(§2)이다.
셋 다 시간형 해자라 본업 있는 1인 운영과 궁합이 맞다 — 자는 동안 쌓인다.

## 2. 테제 — 채점 엔진이 제품이고, 커뮤니티는 엔진의 2단계 고객이다

한국 리테일 정보판(종토방·텔레그램·유튜브)은 "말은 많은데 아무도
채점당하지 않는" 구조이고, 그 불신이 미충족 수요다(미국은 TipRanks가 이
모델로 회사를 만들었다). 채점의 근거를 주관 평가(투표는 인기투표가 되고,
운영자 큐레이션은 1인 운영에서 지속 불가)가 아니라 **시간이 검증하는 객관
성과**에 두면:

- 검증된 트랙레코드는 떠날 수 없는 이유(스위칭 코스트)가 되고,
- "실제로 맞히는 사람이 누구인가"는 긁어갈 수 없는 소유 데이터가 되고,
- 채점 인프라는 이미 가진 시세 파이프라인·지표 계산기와 겹친다.

**순서가 통설과 반대다.** 커뮤니티는 배포 채널을 소비하지 생성하지
않는다 — 지금 트래픽에서 게시판을 열면 빈 게시판이 하나 늘 뿐이다.
엔진을 유저 없이 **공시 주체**에 먼저 돌려 그 출력(성적표)을 유입
콘텐츠로 쓰고, 사람이 모이면 같은 엔진에 유저 콜을 얹는다. 각 층은
단독으로 가치가 있어 다음 층이 실패해도 앞 층은 남는다.

| 층 | 무엇 | 상태 |
|---|---|---|
| L0 | 데이터 표시 (현재 사이트 전부) | 라이브 |
| L1 | 공시 채점 콘텐츠 — 5% 성적표·바이오 아웃컴 | **← 지금 본선** |
| L2 | 계정 + 콜 보드 (유저 기록부) | §6 게이트 통과 후 |
| L3 | 커뮤니티 (글·댓글) + 크리에이터 옵트인 배지 | 마지막 |

## 3. 언어 — 한국어 단일 (판정)

근거 넷이 같은 방향을 가리킨다:

1. **채점이 국내 종목만 가능하다** (`PLAN_COMMUNITY.md` §5.2 — 미국 가격
   lane 부재. EODHD $700 기각·Twelve Data 경로 없음, 등록부 §6.5).
   킬러 기능이 한국에서만 작동한다.
2. **수요 격차가 한국에 있다.** 영어권은 TipRanks·Quiver·Unusual Whales로
   포화, 한국엔 채점당하는 판이 없다.
3. **번역된 UGC 커뮤니티는 죽은 커뮤니티다.** 정착이 없고 영어 게시물
   모더레이션 의무(명예훼손·증권 표현)만 늘린다.
4. **서학개미 wedge** — "미국 데이터를 한국어로"가 경쟁이 얇은 방향이지
   그 반대가 아니다. PTR·13F·내부자에 대한 한국어 커버리지는 얇다.

데이터 페이지의 기존 EN은 유지하되 확장하지 않는다. L2·L3은 한국어만.
AI 번역은 기술 문제가 아니라 가치 문제라 결론이 안 바뀐다.

## 4. 단계 계획

### Phase 0 — TWA 파이프라인 (병행 트랙, 별도 세션)

**왜 지금인가**: Play 신규 개인 계정은 프로덕션 전 비공개 테스트
의무(현행 테스터 12명·14일 연속 옵트인 — 정책 변동이 있었으니 콘솔
문구로 확정)에 계정 신분 검증까지, 코드와 무관한 대기가 3~5주다.
성장 레버가 아니라 **인프라 선행**이다 — 리텐션 훅(알림·관심종목) 없는
앱은 설치를 부르지 않는다는 기대치는 유지한다.

- 범위(repo): `manifest.webmanifest` + maskable 아이콘(브랜드 락업 #109
  파생) + 최소 서비스워커 + `/.well-known/assetlinks.json` 라우트.
  MIME 테스트 동봉(`.webp text/plain` 사고와 같은 클래스).
- **함정 ①**: 서비스워커 캐싱은 "배포해도 화면이 안 바뀌는 사고"(08-25,
  배치 blob)의 클라이언트판이고 이번엔 강제 수집 같은 복구 수단이 없다.
  규칙 — HTML·JSON은 network-first(사실상 캐시 안 함), 캐시는 해시된
  정적 자산 + 오프라인 폴백만, SW 갱신 즉시.
- **함정 ②**: assetlinks 지문은 **Play App Signing 키**(콘솔 → 앱
  무결성)이지 업로드 키가 아니다. 틀리면 앱에 주소창이 뜬다. 순서:
  첫 AAB 업로드 → 지문 확보 → assetlinks 배포 → 검증.
- 크리티컬 패스: 테스터 12명 모집(코드 밖).
- 데이터 세이프티 폼은 지금이 "수집 0"이라 최단 — **계정 시스템 전에
  통과해 둔다.**
- 배포는 안 바뀐다: 웹 배포 = 앱 콘텐츠 배포. 앱 셸 재업로드는 연 1회
  수준(target SDK), 앱용 CI는 만들지 않는다.
- iOS 보류: TWA 같은 공식 경로가 없고 웹뷰 래퍼는 심사 4.2 리젝 리스크.
  네이티브 가치(푸시·위젯)가 생긴 뒤 재검토.

### Phase 1 — 공시 스코어보드 (엔진 v0) ← 본선

**사람이 아니라 공시를 채점한다.** 그리고 **시제가 제품을 가른다**
(2026-08-26 운영자 의문 "회고 통계가 흥미·재방문을 만드나"에 대한 교정 —
의문이 맞았다):

- **회고 집계**("5% 공시 후 평균 −X%p")는 한 번 읽으면 끝이라 재방문이
  없다. 역할은 **신뢰 층 + 일회성 확산 소재**로 강등한다.
- 전면은 **진행 중 추적(스코어보드)**이다: 공시 하나 = 추적 카드 하나 —
  종목·보고자·공시일 기준가(동결)·**D+n**·현재 수익률·지수 대비·1M/3M/6M
  체크포인트. 끝난 카드는 아카이브로 내려가 집계에 합류한다. 지난 시즌
  통계가 아니라 진행 중인 경기를 보여 준다.
- 재방문 루프 세 개가 계정 없이 성립한다: ① 매일 새 공시가 새 카드를
  만든다(심장박동 — feed 큐레이션이 이미 매일 걷는 소스) ② D-day·
  체크포인트 도달이 "다시 볼 이유"를 만든다 ③ Phase 0 트랙의 웹 푸시는
  브라우저 구독이라 **계정 없이** "이 카드 추적 알림"이 가능하다 — 두
  트랙이 여기서 만난다.

대상 판정:

| lane | 데이터 | 채점 | 판정 |
|---|---|---|---|
| 5% 대량보유 추적 보드 | DART 공시(feed 큐레이션 라이브) + FSC 종가 | 카드별 D+n 라이브 + 1/3/6개월 체크포인트, 지수 대비 초과수익 | **1순위 — 대중 진입 담당**. 재미의 원천은 보고자 이름(운용사·슈퍼개미·오너)이고 카드에 표시하는 건 공시 사실 그대로라 안전, 랭킹화만 §표현 규칙에 따라 보류. 선행 프로브 필수(§4.1) |
| 바이오 이벤트 D-day + 아웃컴 | 임상·FDA·식약처(라이브) + KR 종가 | 다가오는 이벤트 캘린더(D-day) → 발표 후 추적 + 성사/불발 | **2순위 — 니치 리텐션 담당, 대중 진입용 아님**(운영자 지적대로 마이너하다. 그러나 KOSDAQ 바이오는 국내에서 가장 이벤트에 광적인 리테일 세그먼트이고, 이 데이터 결합은 우리만 있다 — "어려움"은 약점이 아니라 진입장벽이다). 프레임은 연구 보고서가 아니라 캘린더+추적. 선행 과제: 스폰서↔티커 매핑(ROADMAP #8 보류분) |
| 국민연금 편입/제외 | 연 1회 파일 | 연간 성과 | 보조. 2026-09-30 파일 갱신 때 같이 |
| KR 내부자 | DART 임원·주요주주 보고(미수집) | 매수 후 수익률 | 다음 데이터 축과 채점 소재를 겸한다. "회장이 자사주를 샀다"는 5%보다 직관적인 카드라 수집이 열리면 보드에 합류 |

**채점 불가 목록 — 이유가 각각 다르다:**

- 미국 수익률(PTR·13F·내부자 성과): 가격 lane 부재. **기록(스냅샷)은
  계속 쌓는다** — lane이 열리는 날 소급 채점한다. 동결해 둔 기록은
  나중에 만들 수 없는 종류다.
- 애널리스트 목표가: 증권사 리포트 저작권(ROADMAP #5 ❌), FnGuide 법인
  벽(등록부 §6.6).
- 유튜버·개인 채널: **사실적시 명예훼손**(형법 §307①·정통망법 §70① —
  진실이어도 형사 리스크, §310 공익 항변은 싸워서 얻는 것). Phase 3의
  옵트인 신청제로만 한다.

**표현 규칙 둘** (첫 페이지부터):

1. 집계·이벤트 단위로 말한다("5% 신규 진입 공시 후 평균 초과수익
   −X%p"). **보고자 단위 랭킹**("OO운용 성적")은 법인 상대 명예훼손
   검토 전 보류.
2. 기록·통계로만 말하고 추천 표현을 쓰지 않는다. `/weekend`의 "묻고
   아니라고 답하는" 문법과 같은 계열 — 테스트가 문구를 지키게 한다.

**엔진 v0 산출물** = L2가 그대로 물려받는 것들: 콜 객체 스키마(대상·
방향·기간·기준 스냅샷), 스냅샷 동결 저장, 기간 도래 채점 잡, 리더보드
렌더. 유저 대신 공시 주체로 먼저 검증한다.

**발행 문법은 `/weekend`와 같다**: 롱테일 질의에 답하는 SSR 페이지
("OO 5% 공시 그 후"), 사이트맵·내부 링크, 상류 호출 없는 요청 경로.

**배포는 코드가 못 한다** — 색인 5개·외부 링크 0의 사이트에서 SEO는
보조 채널이고 느리다(08-25 진단: 크롤 예산은 권위에서 온다). **1차
채널은 운영자의 외부 포스팅**이다(`PLAN_COMMUNITY.md` §3의 유입 방식
그대로): 보드가 "퍼갈 수 있는 표·이미지 한 장"을 산출하도록 만들고,
운영자가 외부 커뮤니티·SNS에 올리고 링크한다. 이미 라이브인 미국
스마트머니(PTR·13F — 채점 없이도 소비되는 검증된 포맷)도 같은 포스팅
소재다. §6의 8주 게이트는 "포스팅을 실제로 했다"를 전제로 읽는다 —
안 퍼뜨린 콘텐츠의 불발은 콘텐츠 가설의 기각이 아니다.

#### 4.1 선행 프로브 (코드 전에 — 13F CUSIP처럼)

1. DART 과거 대량보유 공시 소급 조회 범위·형태 실측
2. FSC 시세 과거 일자(basDt) 조회 커버리지 — 소급 채점이 몇 년까지
   가능한가
3. 실제 공시 2건을 손으로 채점해 함정 수집(정정 공시, 거래정지 종목,
   상장폐지, 권리락 조정 — 종가 원천이 수정주가인지 확인)

### Phase 2 — 계정 + 콜 보드 (게시판이 아니다)

콜 + 한 줄 논거(500자)만 받는 **기록부**. 자유 게시판 대비 모더레이션
표면이 한 자릿수로 줄어 1인 운영과 맞는다.

- 콜 객체: 종목코드 · 방향 · 기간 버킷(1주/1M/3M/6M) · 기준가(게시
  시점 종가 동결) · 선택 목표가. 바이오는 이벤트 콜(이벤트+기한+예/
  아니오 — 가격 없이 채점 가능). 미국 종목 콜은 접수·동결만, 채점은
  가격 lane 이후 소급.
- **설계 4원칙 — 하나라도 빠지면 랭킹이 죽는다:**
  1. 스냅샷 동결 + 삭제해도 기록 유지 (생존편향 차단)
  2. 지수 대비 초과수익 채점 (강세장에선 롱 콜 전원이 적중한다)
  3. 표본 정직 — 10콜 미만은 "기록 축적 중", 기간 버킷별 랭킹 분리
     (안 나누면 판이 단타로 수렴한다)
  4. 다계정 억제 — 열람은 익명 유지, **콜 등록에만** 휴대폰 본인인증
     (건당 비용 실측 필요). 계정 10개로 방향을 나눠 걸면 하나는 천재가
     된다.
- 값을 치르는 것: 개인정보 0 상태를 잃는다(`PLAN_COMMUNITY.md` §6).
  방침·약관 개정, 수집은 최소로.
- 스택: ROADMAP §2의 재검토 조건("관심종목·알림·계정 같은 진짜 상태")이
  정확히 이때 충족된다 — Astro 아일랜드 검토, CSR React 아님.
- 알림·관심종목도 이 계정 위에 얹는다 — 리텐션 프리미티브이자 PWA
  푸시(Phase 0의 SW)가 존재하는 이유. 한국 한정 재방문 채널로 카카오톡
  채널도 비교한다.

### Phase 3 — 커뮤니티 + 옵트인 배지

- 글·댓글 개방, 글에 콜 0..N개 첨부. **랭킹 자격제**: 글은 자유(산업
  리서치 환영), 랭킹·배지·성적표는 **콜에서만** 계산. 콜 없는 저자는
  "기록 없음" 표시일 뿐 배제되지 않는다 — "전부 강제 vs 전부 선택"은
  잘못된 이분법이다.
- **beachhead는 KOSDAQ 바이오**: 데이터가 유일급이고(임상+FDA+식약처
  결합), 이벤트 콜이라 채점이 깨끗하고, 논쟁 문화가 강한 정보 갈증
  니치다. "모두의 주식 커뮤니티"로 토스·네이버와 정면 대결하지 않는다.
- **크리에이터 옵트인 배지**: 채널이 **신청하면** 공개 콜을 채점해
  배지를 단다. 명예훼손 구조를 신청제(동의)로 뒤집는 것 — 좋은 기록을
  가진 쪽이 원해서 오고, 안 받는 쪽의 부재가 말을 한다.
- 모더레이션: 신고 창구·임시조치(30일) 절차를 여는 날 갖춘다
  (`PLAN_COMMUNITY.md` §2 — "몰랐다"가 방어가 되려면 알 수 있는 통로가
  먼저 있어야 한다).

## 6. 게이트와 지표 — 임의 기준임을 인정하고 못 박는다

**L1 → L2 진입 게이트** (채점 콘텐츠 첫 배포 후 8주 측정):

- 자연 유입 일 100 UV 2주 지속, **또는** 외부 자발 언급(커뮤니티·블로그
  링크) 10건.
- 미달 시 계정을 만들지 않는다. 콘텐츠 각도를 바꿔 재시도하거나 L1에
  머문다 — L1은 그 자체로 사이트를 낫게 하므로 실패해도 손실은 코드 몇
  주로 한정된다.

**L2 → L3 진입 게이트**: 본인인증 콜 유저 100명 + 월 신규 콜 300건.
채점 대기열이 커뮤니티를 열 만큼 두꺼운가가 질문이다.

측정 도구: Search Console(`Crawled` 증가 = 길 뚫림 — 08-25 색인 진단의
"다음 확인"과 동일 지표), 서버 로그 UV. 새 계측 인프라는 만들지 않는다.

## 7. 수익화 — 순서만 정해 둔다

무수익(L1~L2 초기) → 광고 → 데이터 쪽. 광고는 공짜가 아니다 — 데이터랩
lane의 무광고 조건(네이버 일반조건 7.3④)을 내리는 대가가 있고, UGC 금융
콘텐츠는 AdSense 심사 리스크(`PLAN_COMMUNITY.md` §6·§7)라 원문 확인이
선행이다. 유료 멤버십은 유사투자자문 신고를 전제로만.

## 8. 리스크 대장

| 리스크 | 대응 |
|---|---|
| 성공하면 토스·네이버가 베낀다 | 방어는 백필 불가능한 축적 기록 + 니치 깊이. 그래서 기록을 일찍 시작하는 것 자체가 전략이다 |
| 1인 운영 모더레이션 부담 | 콜 보드 우선으로 표면 축소, 자유 게시판은 마지막 |
| L1 콘텐츠 불발 | §6 게이트가 손실을 한정. 배운 것(채점 수요 가설 기각)도 산출물이다 |
| 미국 가격 lane 지연 | KR 중심 유지. 미국 콜은 기록만 — KRX·NXT·벤더 협상과 독립적으로 진행 가능 |
| 법률 미확정 | 변호사 확인 항목은 `PLAN_COMMUNITY.md` §7 승계 + 추가 둘: 보고자 단위 랭킹(§4.1 표현 규칙), 본인인증 도입 시 개인정보 처리 위탁 |

## 9. 이 문서가 대체하지 않는 것

실행 순서와 판정 이력은 `ROADMAP.md`가 계속 단일 진실이다. Phase 1
상세 설계(스키마·채점 규칙·페이지 구조)는 착수 시 `PLAN_SCORING.md`로
분리한다. 이 문서는 방향이 바뀌는 날에만 고친다 — 게이트 수치 조정은
변경 이력 한 줄로 남긴다.
