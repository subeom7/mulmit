# 한국·미국 섹션 개편 계획 — hlkr.co.kr 모티브

작성일: 2026-08-18
관련: `docs/DATA_SOURCE_REGISTER.md` §3.9(FSC), §3.10(DART), HIP-3 결정(재검토 2026-09-16), §6 벤더 조사표

hlkr.co.kr의 기능 전부를 후보로 놓고, 우리 원칙(도달 가능 ≠ 재배포 가능, 모든 lane
fail-closed, 수치 발명 금지)으로 하나씩 판정한 문서다. 결론: 킬러 기능인
"기준가 대비 현재 상승률"은 **이미 승인·게이트된 세 lane의 결합**이라 새 권리 없이
지금 구현 가능하고(Phase A), 나머지는 가능/조사/보류/제외로 나뉜다.

## 0. hlkr가 하는 일과 우리의 등가물

hlkr는 Hyperliquid HIP-3 한국 주식 무기한선물을 원화로 환산해 "장 마감 후에도
움직이는 삼성전자 가격"을 보여주는 사이트다. 섹션: 실시간 시세(/market),
고위공직자 보유주식(/officials), 연기금 매매(/pension), ETF 리밸런싱(/etf),
코스피200 야간선물(/futures), ADR 괴리율(/adr), 반도체(/semiconductor),
AI 운세(/jeom), 일일리포트, 방법론(/methodology).

## 1. Phase A — "한국 주식, 지금은" (이번 구현)

### 1.1 지표 정의

**기준가 대비 %** = (HIP-3 마크가격 × 최신 H.10 원/달러) ÷ 마지막 FSC 공식 종가 − 1.
지수(KR200)는 포인트 단위가 코스피 200과 같은 스케일이므로 환산 없이 직접 비교한다.

2026-08-18 08:07 KST 라이브 검증 (연휴: 8/15 광복절·8/17 대체공휴일, 마지막 공식 종가 8/13):

| 심볼 | 마크 | 환산 | 기준가(8/13) | 대비 |
|---|---|---|---|---|
| xyz:SMSN | $198.98 | ×1414.29 = ₩281,415 | ₩268,000 | +5.0% |
| xyz:SKHX | $1,210.00 | ×1414.29 = ₩1,711,291 | ₩1,593,000 | +7.4% |
| xyz:HYUNDAI | $325.29 | ×1414.29 = ₩460,054 | ₩418,500 | +9.9% |
| xyz:KR200 | 1131.5pt | 환산 없음 | 1071.24pt | +5.6% |

KR200 +5.6%가 개별주 수치와 정합 — 스케일·공식 검증 완료. (같은 시각 24h 변화율은
+3~4%대로 별개 지표이며, 카드에 둘 다 표기한다.)

### 1.2 정직성 조건 (등록부 원칙 적용)

- **환율은 실시간이 아니다**: H.10은 주간 릴리스의 일별 공식 고시값. 카드에 환율
  날짜를 명시하고 "실시간 환율 아님"을 고정 표기한다.
- **기준가 날짜 명시**: FSC는 D+1 13시 공개라 연휴엔 수일 전 종가가 기준이 된다.
  "8/13 종가 대비"처럼 날짜를 항상 값 옆에 둔다.
- **김프 제거 없음**: hlkr는 김치프리미엄 조정을 하지만 우리는 무허가 실시간 환율을
  쓸 수 없다. 공식 환율 환산값임을 방법론에 명시하는 것으로 대신한다.
- **현물 호가·시초가 예측 아님** 고지 유지 (기존 HIP-3 문구 재사용).
- 마크 없음·기준가 없음·환율 없음이면 해당 필드는 null + 상태 코드. 절대 만들어내지 않는다.

### 1.3 게이트

- 라우트 전체: `require_hip3_public_display()` — 꺼지면 기존 503 계약
  (`hip3_public_display_pending_rights`). HIP-3 재검토일 2026-09-16 유지.
- FSC 기준가: `series_values_servable(FSC, approved)` 실패 시 official·percent null.
- H.10 환율: `get_economic_series("fx_usdkrw")`의 provider_id+rights_status를
  stress_index와 같은 방식으로 검사. 실패 시 환산 필드만 null (KR200은 영향 없음).

### 1.4 구현 항목

- `app/kr_overnight.py` — 대상 4종(SMSN·SKHX·HYUNDAI·KR200), xyz 스냅샷 1회 +
  store 3회 읽기(kr_listings, kr_index_snapshot, economic_observations)로 조립.
- `GET /api/kr/overnight` — Cache-Control private max-age=15.
- monitor 개편(한국/미국·글로벌 존 분리):
  - hero → 시장 요약(교차 시장 테이프 유지)
  - **[한국 시장]** kr-overnight(신규, hlkr 스타일 큰 원화 카드) → korea-official
    (기존 metric 섹션 상단 이동) → kr-indices(지수군) → weekend-pulse(주말 세션 상세)
  - **[미국·글로벌 시장]** S&P500 히트맵 → 스트레스 지수 → global-assets 이하
  - SECTIONS의 `korean-assets`(합성 카드 2장) 삭제 — kr-overnight가 대체.
- 테스트: 환산 수식, 지수 무환산 경로, fx/기준가/마켓 결손 시 null+상태,
  게이트 503, delisted 스킵.

## 2. Phase B — 조사 후 결정 (다음 순서)

1. ~~**국민연금 지분 변동 (연기금 대체)**~~ → **구현 완료 (2026-08-18, `/api/kr/pension`)**.
   조사 결과와 설계 판단:
   - 공시검색 `list.json`에는 **제출인(flr_nm) 필터가 없다** — D001(주식등의
     대량보유상황보고서)을 기간으로 걷고 클라이언트에서 "국민연금"을 거른다.
     90일 창 ≈ 38페이지 ≈ 40여 요청이라 **요청 경로에 둘 수 없고 ingest 배치
     전용**이다(`refresh_kr_pension`, DART_MAX_AGE 주기). web은 저장된 결과만
     읽고, 첫 배치 전에는 503으로 답한다.
   - 국민연금은 **월초 일괄 보고** 패턴이다: 2026-08-18 라이브 검증에서 90일 창
     140건 중 121건이 7/1 하루에 몰렸고 사이사이 개별 보고(7/31 4건, 8/3 5건)가
     낀다. 화면 문구도 그렇게 말한다.
   - 수치는 `majorstock.json`(회사당 1회)에서 `rcept_no`로 조인한다. 날짜 포맷이
     엔드포인트마다 다르고(list=YYYYMMDD, majorstock=YYYY-MM-DD) "-"는 null로
     전달한다. 상세 조회가 실패한 행은 수치 null + `detail_status`로 남긴다.
   - 관찰된 보고사유 어휘: "단순추가취득/처분", "단순투자목적에서 일반투자목적으로
     보유목적 변경". EN은 닫힌 매핑 + 원문 폴백(내부자 패널과 같은 방식).
2. **고위공직자 재산공개 (KR)** — 조사 완료(2026-08-18), **보류 판정**:
   - 구조화 공공데이터셋은 **없다**. 공식 채널은 관보 PDF(전자관보)와
     공직윤리시스템(PETI)의 위원회별 공개목록 PDF뿐이다. 인사혁신처의 파일데이터는
     "재산을 공개하는 공직유관단체 임원" 같은 **명단**이지 재산 수치가 아니다.
   - 행정안전부 "관보_공직자 재산 공개" OpenAPI(데이터셋 15109164)는 이용허락
     제한 없음·활용신청 자동승인으로 권리는 깨끗하지만, **관보 호수 메타데이터와
     원문 링크만** 준다(1993~2023 표기) — 종목 단위 보유 현황이 아니다.
   - 따라서 hlkr식 인물·종목 표는 연 1회 수백 페이지 관보 PDF 표 파싱이 필요하다.
     공수가 크고 "수치 발명 금지" 기준에서 검증 부담도 크므로 보류. 재평가는
     Phase C(US PTR)와 묶어서 한다. 가벼운 대안(재산공개 관보 발행 알림 인덱스)은
     정직하지만 가치가 얇아 채택하지 않는다.
3. **ETF 시세**: 금융위 증권상품시세정보 활용신청(운영자 1회 액션) 후 kr_stocks와
   동일 패턴. 리밸런싱 일정·구성종목은 별도 소스라 시세만 먼저.

## 3. Phase C — 보류 (외부 의존 해소 시)

- **미국 정치인 거래(PTR)**: 법정 공시라 권리는 깨끗, 파서 공수가 크다. 미국 섹션
  확장 1순위 후보로 유지.
- **ADR 괴리율**: Tiingo 견적 회신(2026-08-18) — 재배포 라이선스 최저가
  월 $150(Bootstrap Pilot), $30 개인 티어는 공개 표시 불가. 예산(월 5만원)
  초과라 **보류 확정**. 예산이 월 $150 이상으로 상향되면 재문의 후
  괴리율 = ADR종가 × 환율 ÷ 원주종가 − 1로 구현한다(등록부 §6).
- **일일 리포트·편집 콘텐츠**: 데이터 파이프라인과 별개 논의.
